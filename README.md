# 🔐 Network Intrusion Detection System (NIDS)

A Machine Learning–based Network Intrusion Detection System designed to identify malicious network traffic and potential cyber attacks by analyzing network data and detecting anomalous patterns.

## Project Overview

With the rapid growth of cyber threats, traditional security mechanisms alone are no longer sufficient to protect modern networks.  
This project implements a Network Intrusion Detection System (NIDS) using machine learning techniques to classify network traffic as normal or malicious, enabling proactive threat detection and improved network security.

The system is capable of detecting:
- Denial of Service (DoS) attacks
- Probing and scanning attacks
- Unauthorized access attempts

## Objectives

- Build an intelligent system to detect cyber attacks effectively  
- Preprocess and analyze network traffic data for threat identification  
- Apply machine learning algorithms for intrusion classification  
- Evaluate system reliability using standard performance metrics

## System Workflow

1. Load and preprocess network traffic data  
2. Perform feature selection and normalization  
3. Train machine learning classification models  
4. Evaluate models using performance metrics  
5. Detect anomalous and malicious network activity  

## Machine Learning Models Used

- Logistic Regression  
- Random Forest  
- Support Vector Machine (SVM)  
- K-Nearest Neighbors (KNN)  

## Performance Evaluation

The system is evaluated using:
- Accuracy  
- Precision  
- Recall  
- F1-score  
- Confusion Matrix  

These metrics ensure reliable differentiation between legitimate and malicious network traffic.

## Cybersecurity Relevance

This project demonstrates:
- Anomaly detection

- Threat detection using machine learning
